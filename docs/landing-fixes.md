# Правки лендинга kotelgavno.ru/komplcldcld2/ (июль 2026)

Исходники этого лендинга (Next.js) не найдены ни локально, ни в GitHub
(`lexcrirovs-prog/komplektacii` содержит другую серию `/komplcld*/`; живой
`/komplcldcld2/` собран 23.05.2026 из непушенных исходников). Поэтому правки
внесены **прямо в собранный статический экспорт на хостинге Beget** и должны
быть перенесены в настоящий исходный код, когда он найдётся.

**Бэкап нетронутой версии**: `/kotelgavno.ru/public_html/komplcldcld2_backup_20260706/`
(полная копия каталога до правок). Откат = скопировать бэкап обратно.

## Что изменено на хостинге

### 1. `index.html` + `index.txt`, `__next._full.txt`, `__next._head.txt`
- `og:url` указывал на соседнюю версию `https://kotelgavno.ru/komplcldcld1/` —
  заменён на `https://kotelgavno.ru/komplcldcld2/` (в meta-теге, в инлайновом
  RSC-payload и в txt-payload'ах).
  **В исходниках**: `metadata.openGraph.url` в `layout.tsx` захардкожен на
  komplcldcld1 — вычислять из base path.
- Перед `</body>` подключён `<script defer src="/komplcldcld2/landing-enhance.js">`.

### 2. Новый файл `landing-enhance.js`
Прогрессивные правки после гидрации (DOM-дополнения, ничего не ломают, если
элемент не найден). В исходниках всё это нужно сделать нормальными компонентами:

| Правка | Как в enhance-скрипте | Как должно быть в исходниках |
|---|---|---|
| Плейсхолдер `{{ TODO: Яндекс.Карта iframe с координатами завода Энгельс }}` в секции контактов | Заменяется на iframe `yandex.ru/map-widget/v1/?text=Энгельс, улица Демократическая, 1` | Вставить тот же iframe в JSX (или интерактивную карту на уже подключённом Leaflet). ВАЖНО: статический HTML до гидрации всё ещё содержит TODO-текст (менять его в статике нельзя — hydration mismatch) |
| Кнопок «Посмотреть в 3D» не было | В каждую карточку `#comparison article` добавляется ссылка `https://kotelgavno.ru/komplektacii3/?config=standard\|comfort\|comfort_plus` | Кнопка в компоненте карточки; URL конфигуратора вынести в константу/env |
| Секция `#configurator` называется «3D-конфигуратор», но 3D нет | Добавлена кнопка «Посмотреть эту сборку в 3D →», ссылка собирается в момент клика по текущему выбору («Комплектация X») | Либо встроить iframe конфигуратора, либо кнопка + переименование секции |
| Списки «Подходит, если» дублируются в `#comparison` (полные) и `#configurator` | В `#configurator` блок скрывается, вместо него ссылка «Кому подходит — в сравнении комплектаций ↑» (#comparison); MutationObserver повторяет правку после ре-рендеров React | Убрать дубль из компонента подбора, оставить ссылку |
| Форма КП не знала о выбранной сборке | Читает `?config=…&addons=…`: плашка «Вы выбрали: Комфорт Плюс + деаэратор» над формой + автозаполнение textarea `#task` (через нативный setter + событие input — форма контролируется React) | Обработать searchParams в компоненте формы |

### 3. Не потребовалось
- Логотипы клиентов уже грузятся по относительным путям (`/komplcldcld2/images/logos/…`) —
  пункт про mixed content (`http://kotelgavno.ru/...`) оказался устаревшим.

## Связка с 3D-конфигуратором
- Конфигуратор (новая многофайловая сборка) задеплоен на
  `https://kotelgavno.ru/komplektacii3/`. Принимает `?config=standard|comfort|comfort_plus`
  и `&addons=deaerator,economizer,burner` — открывается сразу на нужной сборке.
- Обратно: кнопка «Получить КП по этой сборке» в конфигураторе ведёт на
  `https://kotelgavno.ru/komplcldcld2/?config=…&addons=…#contact` (URL задаётся
  через `VITE_LANDING_URL` — при переезде на kotelpremium.ru поменять env и пересобрать).
