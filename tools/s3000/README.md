# Построение S-3000, АДЛ, 8 бар

Версия **2026.09.08.2**, дата **2026-09-08**, исполнитель **Codex / GPT-6 Astra**. Входные файлы читаются без сохранения изменений. Промежуточные загрузки и меши размещаются вне репозитория.

## Спецификация и происхождение

`prepare_bom.py` читает только наименования и количества колонок J/K листа S-3000. Взяты варианты для 8 бар: строка 11 — два предохранительных клапана с настройкой 9 бар, строка 32 — два Jetex V4-10. Альтернативные строки 12/33 для 12 бар исключены. Заголовок H1 исходного листа «ЭКОНОМ (АДЛ)» сохранён в метаданных, хотя имя книги начинается со «СТАНДАРТ». Цены не экспортируются.

| Узел | Источник | Применённое исполнение |
| --- | --- | --- |
| Котёл | `PR.3000.01.001(S).stp` / существующий `boiler.glb` | Исходная геометрия, единицы приведены к метрам |
| Экономайзер | `PREMIUM EQS2-3000-3500 (BIM).stp` / `rs_410.glb` | Поворот +90° вокруг вертикальной оси Blender Z |
| Деаэратор | Исходный `deaerator.glb` | Масштаб 1:1; отдельный модуль без обвязки |
| LC220, LC440, BC970 | STEP ATECH | Заводская наружная геометрия приборов на двери шкафа |
| LP200, LP400 | STEP ATECH, длина 500 мм | Стержни удлинены до 1000 мм; наружные головки сохранены |
| CP930 | STEP ATECH, L500 | Электрод проводимости |
| BCV925 | STEP ATECH DN20 PN25 | Клапан продувки по солесодержанию |
| PCF20 | STEP PCF20x20 PN25 DN20xDN20 | В ведомости PCF25-2020; точный артикул требует сверки |
| BCV7432 | STEP ATECH DN32 PN40 | Близкая геометрия к указанному BCV700 / BCV740-220; привод требует сверки |
| SC9 | STEP ATECH | Охладитель проб, отдельный от CP930 |
| RLG-16, клапаны АДЛ, насосы, шкаф, горелка | Параметрические детали по фотографиям | Наружная визуальная геометрия, размеры не аттестованы |
| Обвязка и кабели | Параметрические трассы | Предварительное размещение по видимым портам и фото |

Все 10 архивов и STEP-файлов ATECH имеют ссылки и SHA-256 в [sources.json](../../src/assets/s3000/sources.json). Датчики являются производными от заводской CAD-геометрии; изменения длины и близкие исполнения явно отражены в карточках.

## Экономайзер

Базис сцены Blender: метры, Z вверх, −Y к горелке. Координаты выбраны из цилиндрических поверхностей и торцевых плоскостей исходных STEP. Старые GLB имеют численные координаты в миллиметрах и импортируются с коэффициентом 0,001; этот коэффициент не переносится на новые STEP автоматически.

| Параметр | Значение |
| --- | --- |
| Порт котла в итоговой сцене Blender | `(0, 1.688, 1.060)` м |
| Выбранный порт экономайзера до поворота и переноса | `(-0.507, 0.448, 0)` м |
| Поворот экономайзера | +90° вокруг Z |
| Перенос экономайзера | `(0.448, 2.195, 1.060)` м |
| Внутренний / наружный диаметры обоих патрубков | 450 / 456 мм |
| Расстояние между центрами после преобразования | `1.671217684586219e-7` м |
| Нормали портов | Противоположны |

Разность нижних отметок опор по исходной сетке — около 0,5 мм. Порты совмещены без изменения масштаба деталей. Проверка этих двух портов не подтверждает всю остальную обвязку.

## Повторяемое построение

Проверенная среда: Windows, Blender **3.3.3**, Python **3.11.16**, `cadquery-ocp==7.8.1.1.post1`, Node.js **24.13.1**. Конвертер использует OCP напрямую, без импорта пакета CadQuery. Для чтения Excel нужен `openpyxl==3.1.5`. Среду OCP держите отдельно от Python Blender.

Настройте переменные под свой компьютер. `$repoPath` — корень этого репозитория, `$cachePath` — отдельный рабочий каталог, `$deliveryPath` — папка результата; `$inputPython`, `$cadPython` и `$blenderExe` — пути к соответствующим программам; `$workbookPath` — исходный прайс со вкладкой S-3000.

```powershell
# Однократно установить зависимости в выбранные отдельные среды.
& $inputPython -m pip install -r "$repoPath/tools/s3000/requirements-input.txt"
& $cadPython -m pip install -r "$repoPath/tools/s3000/requirements-cad.txt"
npm install --prefix "$cachePath/gltf" @gltf-transform/core@4.2.1 @gltf-transform/extensions@4.2.1 @gltf-transform/functions@4.2.1 meshoptimizer@0.23.0

& $inputPython "$repoPath/tools/s3000/prepare_bom.py" $workbookPath "$repoPath/src/assets/s3000/bom.json"
& $cadPython "$repoPath/tools/s3000/download_vendor.py" "$cachePath/vendor"
& $cadPython "$repoPath/tools/s3000/convert_step.py" "$cachePath/vendor" "$cachePath/meshes"

# Этот шаг создаёт несжатый GLB, редактируемый .blend и четыре PNG.
& $blenderExe --background --factory-startup --python-exit-code 1 --python "$repoPath/tools/s3000/build_scene.py" -- --repo $repoPath --cache $cachePath --delivery $deliveryPath --render

# Запускать только после успешного завершения Blender.
$env:S3000_GLTF_RUNTIME = "$cachePath/gltf"
node "$repoPath/tools/s3000/optimize_glb.mjs" "$repoPath/src/assets/s3000/s3000-assembly.glb" "$deliveryPath/S3000_ADL_8bar_v2026.09.08.2.glb"
& $inputPython "$repoPath/tools/s3000/verify_assembly.py" "$repoPath/src/assets/s3000"
& $blenderExe --background --factory-startup --python-exit-code 1 --python "$repoPath/tools/s3000/verify_blender_roundtrip.py" -- "$deliveryPath/S3000_ADL_8bar_v2026.09.08.2.glb" "$repoPath/src/assets/s3000/assembly.json" "$cachePath/blender-roundtrip.json"

Set-Location -LiteralPath $repoPath
npm ci
npm run build
```

После каждой команды проверяйте код завершения. Не запускайте оптимизатор, пока Blender строит сцену. Повторная оптимизация уже сжатого входа отклоняется до перезаписи несжатой поставки. Оптимизатор проверяет сохранение имён, числа треугольников и общих габаритов после декодирования.

## Файлы результата и проверки

- `.blend` — редактируемая сборка со студийной сценой. Деаэратор включается в дереве объектов; для четырёх изображений он скрыт из рендера.
- Несжатый GLB **21 217 076 байт** — для повторного импорта в Blender и других 3D-программах.
- Веб-GLB **4 204 832 байта** — Meshopt, 92 именованных узла, 511 193 треугольника и 12 материалов. Его декодер включён в веб-приложение.
- `assembly.json` — 46 компонентов, происхождение, центры для выбора и соответствие строкам спецификации.
- `bom.json` — 27 выбранных строк, 37 единиц или комплектов, ссылки на ячейки, без цен.
- PNG `front-left`, `front-right`, `economizer`, `level-detail` — четыре проверенных ракурса 1600×1100.

Повторный импорт несжатого GLB в чистый Blender сохранил все 46 компонентов; максимальная разница границ — `2.384185791015625e-7` м. Meshopt сохранил число треугольников и имена; отклонение общих габаритов — `6.5699191051926675e-6` м. Это проверки преобразования данных, а не допуск изготовления. Инженерная приёмка, проверка всех соединений, испытание на физическом телефоне и подготовка к печати STL остаются **NOT_VERIFIED / NOT_RUN**.
