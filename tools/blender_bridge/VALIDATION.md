# Проверка выпуска 2026.09.08.1

Дата: 08.09.2026. Исполнитель: Codex / GPT-6 Astra.

## Подтверждено на локальном компьютере

- Windows, Blender 3.3.3, Python 3.13.1, официальный MCP SDK 1.30.0.
- MCP `initialize` согласовал протокол `2025-11-25`.
- `tools/list` вернул ровно 12 ожидаемых инструментов.
- Тестовый куб создан, перемещён и повторно прочитан по MCP.
- Два сохранения с одинаковым пользовательским именем создали разные копии.
- После отключения и нового MCP-соединения сохранённая сцена открылась,
  положение тестового объекта сохранилось.
- Настоящий `boiler.glb` импортирован с коэффициентом 0.001, экспортирован в GLB
  и отрендерен CPU Cycles в PNG 768×576; изображение просмотрено.
- Габариты импортированной сетки в метрах: 2.085943 × 3.469252 × 2.130500.
  Это проверка переноса числовых координат, не инженерная аттестация размеров.
- SHA-256 всех восьми исходных GLB до и после проверки совпали.
- Попытки выхода из каталога, произвольного Python и записи по произвольному
  пути отклонены; состав сцены после этих отказов не изменился.
- Smoke успешно выполнен из рабочей копии и повторно из установленного выпуска.
- `codex mcp get blender --json`: `enabled=true`, STDIO, 12 команд, тайм-аут 180 с.
- Остальные настройки Codex семантически совпали с резервной копией.
- Уже открытый пользовательский Blender сохранил исходный PID и время запуска.
  Все дочерние Blender-процессы smoke завершились.
- 11 unit-тестов проверяют границы файлов, числовые параметры и установщик.
- После перезапуска Codex 8 сентября 2026 года инструменты доступны непосредственно
  в задаче. Повторно выполнены проверка состояния, каталог активов, импорт восьми
  исходных GLB, преобразования, сохранение, экспорт, рендер, открытие сохранённой
  сцены и чтение объектов. Рабочая копия каждого исходного GLB совпала с Git по SHA-256.
- Из PR.3000 и PREMIUM EQS2-3000-3500 сохранена предварительная пара с исходным
  взаимным положением. Сохранённый GLB повторно открыт отдельным процессом Blender:
  два объекта геометрии, 101 962 невырожденных треугольника и габариты
  2.085943 × 3.906252 × 2.131000 м сохранились. PNG 1024×768 просмотрен.
- В исходном GLB котла найдены 24 треугольника с повторяющимися индексами и нулевой
  площадью. Blender исключил их при первом импорте. Количество остальных треугольников
  в Blender до экспорта и после повторного импорта GLB совпало.
- Состав библиотеки, пределы совмещения и расхождения текущего конфигуратора
  описаны в [ASSET_READINESS.md](ASSET_READINESS.md).

## Границы результата

Статус: **PASSED_LIVE_LOCAL_MCP + PASSED_CODEX_NATIVE_MCP + PASSED_GLB_ROUNDTRIP**.

Проверены реальный MCP-клиент SDK, установленный Blender и вызовы непосредственно
из задачи Codex после перезапуска. Дополнительный перезапуск для этой версии не нужен.

Выпуск работает с отдельной фоновой сценой. Подключения к существующему GUI-окну,
AutoCAD, Plant 3D и публикации на сайте в этот этап не входят. Конфигуратор и
CAD-исходники не изменялись.

Полные машинные протоколы, GLB, Blender-копии, журналы и резервная копия
настроек находятся в локальном каталоге установки. В GitHub включены только
каталог активов и контрольное изображение предварительной пары.
