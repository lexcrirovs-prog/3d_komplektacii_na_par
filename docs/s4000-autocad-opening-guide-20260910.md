# PREMIUM S-4000 — AutoCAD с открывающимися дверями

Версия **2026.09.11.1** от **11.09.2026**, исправленная на месте по видео `2026-09-11 14-17-47.mkv`. Исполнитель: **Codex / GPT-6 Astra**.

Сборка «Комфорт», котлы **8–12 бар**. Текущий подбор оборудования — 12 бар; общий внешний вид для двух давлений согласован владельцем. Источник этой редакции — Blender `2026.09.11.1`. FV8 установлен на пол, ДА-15 поднят на 1 м на раме под обеими сёдлами. В конденсатную линию FV8 → BDV установлен Стимакс А31 DN25 Ф/Ф из DWG производителя. Сохраняются двери, исправленный отвод группы давления и разворот ДА-15 на 180°.

Замкнутая O-образная петля заменена непрерывным отводом с плавным верхним изгибом по образцу предоставленного чертежа ДА-15-8. Сохранены два реле, преобразователь давления и манометр. По видео от 11.09.2026 вентиль поднят над коллектором и подключён через отвод. Три кабеля закреплены вдоль нового отвода и доведены до прежнего кабель-канала и шкафа. Размеры установки и состав приборов деаэратора на котёл не переносились; владелец подтвердил изменение формы с сохранением приборов котла.

## Открыть сборку

Распакуйте весь архив в отдельную папку. Запустите **«Открыть в AutoCAD.cmd»**. Этот запуск рассчитан на установленный здесь AutoCAD 2027 по пути `E:\AutoCAD 2027\acad.exe`. Он открывает чертёж и подключает его команды для текущего сеанса.

Для обычного открытия выберите в папке `AutoCAD`:

- **S4000_COMFORT_8-12bar_v2026.09.11.1.dwg** — обе двери закрыты.
- **S4000_COMFORT_8-12bar_OPEN_v2026.09.11.1.dwg** — обе двери уже открыты. Этот файл позволяет сразу увидеть внутренности без загрузки команд.

Формат DWG — **AutoCAD 2018**, единицы — **миллиметры**. Проверено сохранение и повторное открытие в AutoCAD 2027.

Если файл открыт двойным щелчком, введите **APPLOAD**, выберите **S4000-controls.lsp** из той же папки, затем введите **S4000PANEL**. При обычном предупреждении AutoCAD о загрузке сценария выберите разовую загрузку этого файла. Не требуется менять общие настройки безопасности. Файлы `.dcl` должны оставаться рядом с DWG. При переносе DWG в другую папку перенесите туда и файлы управления.

## Двери и виды

Команда **S4000PANEL** открывает панель с кнопками дверей, видами и переходом к выбору оборудования.

| Команда | Действие |
|---|---|
| `S4000OPEN` / `S4000CLOSE` | Открыть / закрыть обе двери |
| `S4000DOOROPEN` / `S4000DOORCLOSE` | Открыть / закрыть только котёл |
| `S4000CABINETOPEN` / `S4000CABINETCLOSE` | Открыть / закрыть только шкаф |
| `S4000VIEW` | Общий вид |
| `S4000DOORVIEW` | Крупный вид двери и трубок котла |
| `S4000CABINETVIEW` | Крупный вид шкафа |
| `S4000DAVIEW` | Вид развёрнутого деаэратора |
| `S4000PRESSUREVIEW` | Крупный вид исправленной группы давления |
| `S4000BLOWDOWNVIEW` | Обвязка FV8 и BDV60/5 |
| `S4000TRAPVIEW` | Крупный вид конденсатоотводчика А31 |
| `S4000ROUTINGVIEW` | Общий вид новых трубопроводов |
| `S4000PUMPS` | Вид насосов |
| `S4000REAR` | Вид сзади |

Дверь котла поворачивается на **105°** вместе с горелкой. Дверь шкафа — на **110°** вместе с приборами. Команды ставят дверь в заданное положение; повторное нажатие не прибавляет угол. Подвижны только семь обозначенных блоков. Корпуса и монтажная панель остаются неподвижными. Для отмены одного действия используйте штатную команду **U**.

Для вращения модели используйте **Shift + средняя кнопка мыши** или **3DORBIT**. Если вид потерян, введите **S4000VIEW**. Эта подробная версия содержит всю геометрию; время открытия зависит от компьютера.

## Комплектация и трубы

Введите **S4000OPTIONS**. Независимо включаются экономайзер, деаэратор, модуляция питательной воды, ГПЗ и два сепаратора. Подтвердите выбор кнопкой **OK**. Положение дверей при переключении оборудования сохраняется.

- С экономайзером: насосы → нижний вход экономайзера → верхний выход → модуляция при выборе на горизонтальном участке у котла → штатный задний DN32 котла.
- Без экономайзера: насосы → модуляция при выборе → штатный задний DN32 котла.
- Без деаэратора остаётся подвод воды со стороны деаэратора до насосов.
- ГПЗ находится на подающем паропроводе. При её отключении отображается прямой участок.
- Между выходом дымовых газов и экономайзером сохранена проставка **500 мм** в цвет экономайзера.
- Деаэратор ДА-15 развёрнут целиком вместе с колонкой, указателем уровня, соединениями, оцинковкой и опорами. Его выход заново подсоединён к общему всасывающему коллектору насосов.
- Непрерывная продувка направлена в FV8. Если FV8 отключён, а BDV включён, отображается отдельная линия к BDV. При отсутствии обоих аппаратов остаётся граница внешней системы.
- Периодическая продувка имеет основную ветвь с ручным вентилем и BCV7432, а также ручной обход. После объединения ветвей труба идёт в BDV.
- Конденсат FV8 проходит через А31 DN25 в BDV. А31 включается вместе с FV8. До А31 труба понижается, после него показан напорный подъём 1125 мм. Табличка **KO / MISSING** удалена. Рабочий перепад давления и пропускная способность А31 остаются на расчёте.
- Линия вторичного пара FV8 к ДА удалена. Предохранительный клапан установлен на малый верхний DN25 по подтверждению владельца. Отбор SC9 идёт от круглого торца BCV925 напротив привода; принимающий штуцер SC9 ещё требует уточнения.
- Вентиляция BDV, сливы, охлаждающая вода и отдельные отводы предохранительных клапанов заканчиваются границами внешних систем. Оборудование из более богатой комплектации не добавлено.

Внутри котла показаны **96 дымогарных труб и одна жаровая труба** из полного конструкторского STEP именно S-4000. Прочие 571 деталь этого STEP не добавлены. Внутренности шкафа выполнены по предоставленной фотографии; точная компоновка шкафа «Комфорт» остаётся в списке уточнений.

## Устройство файла

Каждый узел имеет отдельные блок и слой `S4000_...`. Геометрия передана без уменьшения числа полигонов: это подробные штатные **MESH-объекты AutoCAD внутри блоков**. Узлы можно перемещать, скрывать и заменять по отдельности. История построения исходных твердотельных деталей в DWG не восстанавливается.

Не переименовывайте блоки и слои, если используете прилагаемые команды дверей и комплектации. После изменения сцены сохраняйте собственную рабочую копию.

В комплекте лежат ведомость оборудования без цен, перечень временных моделей, контрольные виды AutoCAD и отчёты проверки. Ведомость унаследована от согласованной сборки `2026.09.10.1`. Сопоставление всех участков и отсутствующие узлы описаны в **«Проверка-обвязки.md»**. Точные размеры заменителей и компоновка шкафа перечислены в **«Недостающие-модели.md»**.
