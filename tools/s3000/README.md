# Подробная сборка S-3000, АДЛ, 8 бар

Версия **2026.09.08.3**, дата **2026-09-08**, исполнитель **Codex / GPT-6 Astra**. Входные CAD, фотографии и книги Excel читаются без сохранения изменений. Рабочие копии DWG, DXF, загрузки и промежуточные меши находятся вне репозитория.

## Состав и происхождение

`prepare_bom.py` читает наименования и количества J/K листа S-3000. Выбраны строки для 8 бар: строка 11 — два предохранительных клапана с настройкой 9 бар; строка 32 — два Jetex V4-10. Альтернативные строки 12/33 исключены. Заголовок H1 «ЭКОНОМ (АДЛ)» сохранён в метаданных. Цены не экспортируются. Ведомость содержит 27 позиций, 37 единиц/комплектов; итоговая сцена — 46 выбираемых компонентов.

## Установленные положения

Базис Blender: метры, Z вверх, −Y к горелке. Границы `bounds_blender` записаны в этом базисе. Поле `center` предназначено для браузера glTF: Y вверх.

| Узел | Положение в Blender, м |
| --- | --- |
| LP200 | `(0, -0.8925, 2.1185)`, резьбовое отверстие переднего большого фланца |
| LP400 | `(0, -0.485, 2.1185)`, следующий фланец |
| Боковой приборный коллектор | Корневой объект `(1.18, -0.66, 0)`, поворот Z +90°; боковой отвод над стёклами, овальная петля сифона, три реле, манометр, вентиль |
| Горелка | Корневой объект `(0, -1.707, 0.282)`, поворот Z 180°; фланец по исходной геометрии DWG |
| Деаэратор | Корневой объект `(-4.25, 0.30, 0)`, отдельный модуль |

Монтаж LP200/LP400 соответствует **последнему скриншоту владельца от 17:29 с подписями**. Он уточняет прежнюю текстовую нумерацию фланцев. Третий датчик не добавлялся. Место датчика за главным паровым вентилем освобождено.

Дымовой порт котла `(0, 1.688, 1.060)`, исходный порт экономайзера `(-0.507, 0.448, 0)`. После поворота +90° и переноса `(0.448, 2.195, 1.060)` центры совпадают с разницей `1.671217684586219e-7` м, нормали противоположны. Внутренний/наружный диаметры обоих патрубков — **450/456 мм**. Масштаб не изменён; нижние отметки опор отличаются примерно на 0,5 мм. Проверка этих двух портов не подтверждает всю остальную обвязку.

Параметры предварительного ДА-25/15 хранятся в [da25-reference.json](da25-reference.json): длина по чертежу 6450 мм, диаметр бака без изоляции 2220 мм, межопорное расстояние 3460 мм. Внешние габариты визуальной модели около 6440×2328×4369 мм; толщина изоляции 50 мм, форма отдельных деталей и раскрой листов восстановлены приблизительно. Замена исполнения бака требует изменения этих параметров и повторного построения.

## Повторяемое построение

Проверено на Windows, Blender **3.3.3**, AutoCAD Core Console **2027**, Python **3.11.16**, Node.js **24.13.1**. OCP используется напрямую, отдельно от Python Blender. Зависимости закреплены в `requirements-cad.txt` и `requirements-input.txt`. Модуль `detail_geometry.py` использует стандартный Python и Blender.

Укажите пути: `$repoPath` — репозиторий; `$cachePath` — отдельная рабочая папка; `$deliveryPath` — новая папка поставки; `$cadPython`, `$inputPython`, `$blenderExe`, `$autocadCoreExe` — исполняемые файлы; `$workbookPath`, `$burnerDwgPath` — частные исходники. Копии исходных STEP котла/экономайзера должны лежать в корне репозитория, логотип — в `src/assets/s3000/premium-logo.png`.

```powershell
& $inputPython -m pip install -r "$repoPath/tools/s3000/requirements-input.txt"
& $cadPython -m pip install -r "$repoPath/tools/s3000/requirements-cad.txt"
npm install --prefix "$cachePath/gltf" @gltf-transform/core@4.2.1 @gltf-transform/extensions@4.2.1 @gltf-transform/functions@4.2.1 meshoptimizer@0.23.0

& $inputPython "$repoPath/tools/s3000/prepare_bom.py" $workbookPath "$repoPath/src/assets/s3000/bom.json"
& $cadPython "$repoPath/tools/s3000/download_vendor.py" "$cachePath/vendor"
& $cadPython "$repoPath/tools/s3000/prepare_detail_meshes.py" $repoPath $cachePath

# Для каждого экспорта нужна новая пустая папка. Исходный DWG не открывается на запись.
& $cadPython "$repoPath/tools/s3000/export_dwg.py" $burnerDwgPath "$cachePath/detail/rs410-export" --autocad $autocadCoreExe
& $cadPython "$repoPath/tools/s3000/convert_burner_dxf.py" "$cachePath/detail/rs410-export/output.dxf" "$cachePath/detail/burner-dwg.json.gz"

# Строит несжатый GLB, .blend с упакованными текстурами и восемь PNG.
& $blenderExe --background --factory-startup --python-exit-code 1 --python "$repoPath/tools/s3000/build_scene.py" -- --repo $repoPath --cache $cachePath --delivery $deliveryPath --render

# Только после успешного завершения Blender.
$env:S3000_GLTF_RUNTIME = "$cachePath/gltf"
node "$repoPath/tools/s3000/optimize_glb.mjs" "$repoPath/src/assets/s3000/s3000-assembly.glb" "$deliveryPath/S3000_ADL_8bar_v2026.09.08.3.glb"
& $inputPython "$repoPath/tools/s3000/verify_assembly.py" "$repoPath/src/assets/s3000"
& $blenderExe --background --factory-startup --python-exit-code 1 --python "$repoPath/tools/s3000/verify_blender_roundtrip.py" -- "$deliveryPath/S3000_ADL_8bar_v2026.09.08.3.glb" "$repoPath/src/assets/s3000/assembly.json" "$cachePath/detail/blender-roundtrip.json"

Set-Location -LiteralPath $repoPath
npm ci
npm run build
```

После каждой команды проверяйте код завершения. Экспортёр DWG проверяет неизменность SHA-256 оригинала. Конвертер горелки проверяет миллиметры, один блок без поворота/масштабирования и тип polyface. Оптимизатор не принимает уже сжатый GLB, чтобы не перезаписать несжатую поставку. Он проверяет сохранение имён, числа треугольников и общих габаритов после декодирования.

## Выходные файлы и проверка

- `.blend` — 46 корневых компонентов с геометрией, две упакованные текстуры и студийная сцена. Для редактирования отдельного винта используется режим редактирования меша соответствующего компонента. Деаэратор доступен в дереве объектов; в начальном ракурсе рендера он скрыт.
- Несжатый GLB — **95 778 544 байта**, повторно импортирован в чистый Blender.
- Веб-GLB — **12 773 684 байта**, **2 194 136 треугольников**, 92 именованных узла, 18 материалов, две текстуры. Meshopt сжимает данные без сокращения геометрии; декодер включён в страницу.
- `assembly.json` — 46 компонентов, происхождение, положения датчиков и соответствие ведомости. `bom.json` — 27 выбранных строк без цен.
- PNG **2000×1400**: `front-left`, `front-right`, `economizer`, `level-detail`, `burner-detail`, `sensor-detail`, `deaerator-detail`, `deaerator-cladding`.

Повторный импорт несжатого GLB сохранил все 46 компонентов; максимальная разница границ — `2.384185791015625e-7` м. Meshopt сохранил число треугольников и имена; разница общих габаритов — `0.0000378775593707914` м. Это проверка преобразования данных, а не допуск изготовления.

Фактические результаты сборки, браузера, исходников и MCP записаны в [протоколе версии 3](../../docs/s3000-detail-verification-20260908.json). Инженерная приёмка, испытание на физическом телефоне, размещение на сайте компании, реконструкция котельной и подготовка к 3D-печати в этот результат не входят. Для воспроизведения геометрии горелки нужен оригинал DWG, который не публикуется в репозитории.
