Новая страница сравнивает комплектации в режиме директора и раскрывает состав в режиме проектировщика. Состояние выбора сохраняется в URL. Каталог содержит девять котлов, три комплектации, два давления и каскады из одного–пяти одинаковых котлов. HTML-интерфейс не требует загрузки 3D. Лёгкая сцена подключается отдельно; подробная геометрия используется по запросу.

## Запуск и проверка

Команды выполняются из `sites/komplektacii5` внутри репозитория. Требуется Node.js 24 для тестов TypeScript и генераторов; серверу Beget нужен PHP для формы.

```powershell
npm ci
node tools/prepare-documents.mjs
node tools/prepare-detail.mjs
# For PHP tests: provide an installed PHP CLI path, e.g.
# $env:PREMIUM_PHP_BIN = 'C:\path\to\php.exe'
npm test
npm run build
npm run dev
```

Dev: `http://127.0.0.1:5185/`. Сборка создаёт `dist/`, затем `tools/release.mjs` записывает `dist/DEPLOY_MANIFEST.json` с SHA-256 файлов, датой, версией, исполнителем и исходным commit. `npm run preview` открывает собранную страницу на том же порту; dev и preview нельзя запускать одновременно на 5185.

```powershell
node tools/prepare-documents.mjs --check
npm test
npm run build
```

`--check` только проверяет существующие копии. Генератор документов читает `public/data/documents-manifest.json`, если файл существует, иначе действующий `public/data/docs-manifest.json`. Он проверяет размер, SHA-256 и Git blob исходного commit до копирования. Девять STEP и семь PDF записываются по `href`; исходный логотип — в `public/premium-logo.png`. Для другого расположения pinned-репозитория задаётся `PREMIUM_DOCUMENT_SOURCE`. Текущий APP использует имя `docs-manifest.json`.

Vite не исполняет PHP. Локальная ошибка отправки формы в dev сама по себе не подтверждает неисправность серверного обработчика. Тесты почтового endpoint выполняются отдельным PHP CLI-server в capture-режиме; реальное письмо при этом не отправляется.

## Исходники и структура

Подтверждённый источник: `cc919366206eb317e7f21e90247ed1870cb276cd`. Продуктовые данные, заводские модели и чертежи читаются из этого commit. Новая работа ограничена `sites/komplektacii5`; корневой просмотрщик `/komplektacii4` не редактируется.

| Место | Назначение |
|---|---|
| `src/core.ts` | Нормализация выбора, URL, единая спецификация и сравнение изменений |
| `src/App.tsx` | Режимы директора/проектировщика, сравнение и форма запроса |
| `src/Viewer.tsx`, `src/detailed.ts` | Лёгкая 3D-сцена и подробная геометрия по запросу |

| `public/models/`, `public/detail/`, `public/docs/` | Производные GLB, подробные GLB, оригинальные STEP/PDF |
| `public/api/lead.php` | Серверная проверка и передача запроса КП по email |
| `tests/`, `reports/` | Проверки правил и сохранённые свидетельства подготовки |
| `tools/` | Восстановление ресурсов, LOD pipeline, упаковка и манифест сборки |

Общие ДА/FV/BDV и каскадное оборудование учитываются один раз. Оборудование котла умножается на количество котлов. Модуляция доступна только у «Комфорт» и «Комфорт+»; экономайзер — от S-1500; электрическая ГПЗ включена от S-4000. Цены, проценты экономии, сокращение персонала и точность поддержания давления не выводятся без подтверждённого источника.

## Подготовка 3D

Воспроизводимый генератор находится в `tools/lite/`. Полный алгоритм и ограничения — в его README. Существующие проверенные модели уже лежат в `public/models/`; для обычного изменения интерфейса пересоздавать их не требуется.

```powershell
node --max-old-space-size=8192 tools/lite/build.mjs --pilot
node --max-old-space-size=8192 tools/lite/build.mjs
node tools/lite/verify.mjs
node tools/prepare-lite.mjs
node tools/prepare-detail.mjs
node tools/lite/build-parts.mjs
node tools/lite/check-parts.mjs
node tools/verify-assets.mjs
```

После генерации `prepare-lite.mjs` проверяет SHA-256 всех 105 GLB, копирует только файлы из манифеста в `public/models/`, сохраняет полные свидетельства в `reports/` и запускает упаковку метаданных. При обнаружении постороннего GLB он останавливается до записи. `--pilot` пишет в отдельный `pilot-output/`, полный набор — в `output/`. Сборка LOD использует glTF runtime, указанный в `tools/lite/README.md`; его можно задать через `S3000_GLTF_RUNTIME`. Node 24, Three 0.170.0 и esbuild берутся из локального окружения и зависимостей APP. Генераторы не устанавливают пакеты автоматически.

`build-parts.mjs` воспроизводит лёгкую арматуру деаэратора и каскада из исходных геометрических функций; меняется только число сегментов примитивов. `verify-assets.mjs` проверяет упакованные метаданные, SHA-256 исходников и публичных моделей, наличие узлов спецификации и бюджеты всех 22 400 нормализованных сочетаний. Итоговый отчёт — `reports/asset-integration-qa.json`. Он включает арматуру и трубы, но не сравнение с предыдущей сценой, проходы теней, HTML/JS/JSON и сетевое время загрузки.

GLB используют метры и Y-up. Имена верхних узлов сохраняют семантические ID для подсветки. Данные трасс и pivots исходного просмотрщика имеют Z-up и преобразуются в `[x,z,-y]`. Общие элементы каскада не дублируются. Исходный логотип не перерисовывается.

LOD исключает внутренние трубы, проводку и содержимое шкафов. Для внутренних видов нужна подробная геометрия. Границы упрощённых примитивов корректируются ограниченным локальным преобразованием до 20 мм по оси; проверка bounding box не является проверкой точности поверхности. Заводские STEP и подробные GLB сохранены.

## Почтовый endpoint

`POST /komplektacii5/api/lead.php`, `Content-Type: application/json`. Поля: `requestId` (UUID), `contact` (`name`, `phone`, `email`, `company`, `comment`, honeypot `website`), `configuration` (`power`, `trim`, `pressure`, `cascade`, `addons`), `sourceVersion` для клиентского контекста. Версия в письме задаётся сервером. Получатель фиксирован в обработчике: `premium-gas@mail.ru`; адрес из браузера не используется как получатель.

Сервер проверяет поля и совместимость оборудования, составляет текст по каталогу, добавляет ссылку на выбранную конфигурацию и предотвращает повторную отправку принятого UUID. Лимиты: пять попыток за десять минут на хеш IP и 25 попыток за минуту на приложение. Ответ `200` с `status: accepted` означает, что почтовый транспорт принял запрос; получение письма адресатом проверяется отдельно. Ошибки возвращают статус `error` и HTTP 4xx/5xx; клиент не показывает ложный успех.

Перед запуском на Beget задать `PREMIUM_LEAD_STORAGE` как отдельный приватный каталог **вне `public_html`** с правом записи PHP. Там хранятся хеши, временные метки и состояние обработки, без контактной базы. Не включать его в публичную сборку. Для локальной проверки только PHP CLI-server поддерживает `PREMIUM_TEST_MODE=1` и `PREMIUM_MAIL_TRANSPORT=capture`: текст сохраняется в тестовое хранилище вместо отправки. Эти переменные не включают capture на обычном сервере.

Порядок публикации, границы доступа, приёмка и откат зафиксированы в [описании релиза](docs/RELEASE-2026.10.01.1.md). Фактические проверки Beget, получение контрольного письма и сохранность `/komplektacii4/` зафиксированы в [протоколе публикации](docs/PUBLICATION-2026.10.01.1.md). Замеры FPS, LCP и времени загрузки не следуют из размеров GLB; публиковать их можно только вместе с отдельными результатами браузерных измерений.
