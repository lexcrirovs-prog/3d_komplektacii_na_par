# S-4000 «Комфорт»: Blender, открывание дверей

Дата: 10.09.2026. Версия: 2026.09.10.2. Исполнитель: Codex / GPT-6 Astra.

Запрос владельца: отдельный вариант уже собранного S-4000 в Blender; открываются дверь котла и дверца шкафа.

1. Сохранить принятый выпуск AutoCAD 2026.09.10.1 и его подробную сцену. Новая версия создаётся отдельно.
2. Выделить переднюю дверь из наружной CAD-модели S-4000. Привязать к одной оси дверь, её надписи и горелку. Сохранить корпус и обвязку неподвижными.
3. Подключить к собственной петле уже существующую дверь шкафа вместе с аппаратами и проложенным по двери жгутом. Внутренняя монтажная панель остаётся на корпусе.
4. Для вида за дверью извлечь только 96 дымогарных труб и жаровую трубу из обнаруженного полного STEP S-4000 на 1,2 МПа. Трубки S-3000 не масштабируются. Вид отверстий формируется отдельной простой маской.
5. Добавить независимые оси поворота, ограничение углов и штатную анимацию Blender с подписанными кадрами: закрыто, открыт котёл, обе двери открыты, открыт шкаф.
6. Проверить крайние и промежуточные положения, неподвижность остальных деталей, сохранность источников и повторное открытие файла. Просмотреть изображения обеих дверей и всей сборки.
7. Подготовить самостоятельный комплект Blender с инструкцией и проверками. Зафиксировать изменения отдельным коммитом и подробным draft PR в GitHub.

Управление должно работать штатными средствами Blender без установки дополнений и без автозапуска Python. Комплектация остаётся «Комфорт», внешнее обозначение — котлы 8–12 бар.
