# Подробная сборка S-3000, АДЛ, 8 бар

Версия **2026.09.08.4**, дата **2026-09-08**, исполнитель **Codex / GPT-6 Astra**. Входные CAD, фотографии и книги Excel читаются без сохранения изменений. Рабочие копии DWG, DXF, загрузки и промежуточные меши находятся вне репозитория.

## Состав и происхождение

`prepare_bom.py` читает наименования и количества J/K листа S-3000. Выбраны строки для 8 бар: строка 11 — два предохранительных клапана с настройкой 9 бар; строка 32 — два Jetex V4-10. Альтернативные строки 12/33 исключены. Заголовок H1 «ЭКОНОМ (АДЛ)» сохранён в метаданных. Цены не экспортируются. Ведомость содержит 27 позиций, 37 единиц/комплектов; итоговая сцена — 49 выбираемых компонентов.

## Установленные положения

Базис Blender: метры, Z вверх, −Y к горелке. Границы `bounds_blender` записаны в этом базисе. Поле `center` предназначено для браузера glTF: Y вверх.

| Узел | Положение в Blender, м |
| --- | --- |
| LP200 | `(0, -0.8925, 2.1185)`, резьбовое отверстие переднего большого фланца |
| LP400 | `(0, -0.485, 2.1185)`, следующий фланец |
| Боковой приборный коллектор | Корневой объект `(1.18, -0.66, 0)`, поворот Z +90°; боковой отвод над стёклами, овальная петля сифона, три реле, манометр, вентиль |
| Горелка | Корневой объект `(0, -1.707, 0.282)`, поворот Z 180°; фланец по исходной геометрии DWG |
| Деаэратор | Корневой объект `(-4.25, 0.30, 0)`, отдельный модуль |

Монтаж LP200/LP400 соответствует **последнему скриншоту владельца от 17:29 с подписями**. Он уточняет прежнюю текстовую нумерацию фланцев. Третий датчик не добавлялся. Патрубок за главным паровым вентилем используется для питания котла.

Дымовой порт котла `(0, 1.688, 1.060)`, противоположный исходный порт экономайзера `(0.507, 0.448, 0)`. После абсолютного поворота Z +270° и переноса `(-0.448, 2.195, 1.060)` центры совпадают с разницей `6.800032620939728e-8` м. Нормали противоположны, диаметры обоих патрубков — 450/456 мм, масштаб не изменён.

Водяные фланцы экономайзера: нижний `(-0.525, 2.702, 0.700)`, верхний `(-0.525, 2.702, 1.420)`, нормаль +Y. Они получены из исходных STEP-центров `(-507, -360, 77)` и `(-507, 360, 77)` мм. Верхний питательный порт котла `(0, 0.565, 2.085)` расположен между паровым вентилем и двумя предохранительными клапанами.

Части `feed_to_economizer` и `feed_from_economizer` имеют `requires: ["economizer"]`; `feed_direct` имеет `excludes: ["economizer"]`. Общие коллекторы, верхний питательный вентиль и обратный клапан сохраняются в обеих схемах. Видимость применяется к целому узлу с креплениями и ответными фланцами. Скрытые узлы исключены из выбора мышью.

Девять кабелей заканчиваются внутри нижней зоны шкафа. Кабели LP200/LP400 уложены по площадке и кривизне левой стороны обшивки; провода реле идут вдоль коллектора и сифона, затем по правой стороне. Снизу установлены два боковых лотка с поперечиной и ответвлением к насосам. Под шкафом — вертикальный открытый канал. Геометрический радиус кабелей на цилиндре 934 мм при наружном радиусе 919 мм; крепления доходят до обшивки.

Уровнемер ДА-25 расположен на локальном X = 350 мм, ближе к центру днища. Два патрубка на высотах 310/2110 мм входят за поверхность днища на 120 мм. Накладки диаметром 134 мм имеют отверстие вокруг трубы и повторяют кривизну листа. Повторный импорт GLB проверяет лучами наличие фактической трубы внутри бака.

Параметры предварительного ДА-25/15 хранятся в [da25-reference.json](da25-reference.json): длина по чертежу 6450 мм, диаметр бака без изоляции 2220 мм, межопорное расстояние 3460 мм. Внешние габариты визуальной модели около 6425×2328×4369 мм; толщина изоляции 50 мм, форма отдельных деталей и раскрой листов восстановлены приблизительно. Замена исполнения бака требует изменения этих параметров и повторного построения.

## Повторяемое построение

Проверено на Windows, Blender **3.3.3**, AutoCAD Core Console **2027**, Python **3.11.16**, Node.js **24.13.1**. OCP используется напрямую, отдельно от Python Blender. Зависимости закреплены в `requirements-cad.txt` и `requirements-input.txt`. Модуль `detail_geometry.py` использует стандартный Python и Blender.

Укажите пути: `$repoPath` — репозиторий; `$cachePath` — отдельная рабочая папка; `$deliveryPath` — новая папка поставки; `$cadPython`, `$inputPython`, `$blenderExe`, `$autocadCoreExe` — исполняемые файлы; `$workbookPath`, `$burnerDwgPath` — частные исходники. Копии исходных STEP котла/экономайзера должны лежать в корне репозитория, логотип — в `src/assets/s3000/premium-logo.png`.

```powershell
& $inputPython -m pip install -r "$repoPath/tools/s3000/requirements-input.txt"
& $cadPython -m pip install -r "$repoPath/tools/s3000/requirements-cad.txt"
npm install --prefix "$cachePath/gltf" @gltf-transform/core@4.2.1 @gltf-transform/extensions@4.2.1 @gltf-transform/functions@4.2.1 meshoptimizer@0.23.0

& $inputPython "$repoPath/tools/s3000/prepare_bom.py" $workbookPath "$repoPath/src/assets/s3000/bom.json"
& $cadPython "$repoPath/tools/s3000/download_vendor.py" "$cachePath/vendor"
& $cadPython "$repoPath/tools/s3000/prepare_detail_meshes.py" $repoPath $cachePath

# Для каждого экспорта нужна новая пустая папка. Исходный DWG не открывается на запись.
& $cadPython "$repoPath/tools/s3000/export_dwg.py" $burnerDwgPath "$cachePath/detail/rs410-export" --autocad $autocadCoreExe
& $cadPython "$repoPath/tools/s3000/convert_burner_dxf.py" "$cachePath/detail/rs410-export/output.dxf" "$cachePath/detail/burner-dwg.json.gz"

# Строит несжатый GLB, .blend с упакованными текстурами и тринадцать PNG.
& $blenderExe --background --factory-startup --python-exit-code 1 --python "$repoPath/tools/s3000/build_scene.py" -- --repo $repoPath --cache $cachePath --delivery $deliveryPath --render

# Отдельные GLB с одной схемой питания, без отдельного деаэратора.
& $blenderExe --background --factory-startup --python-exit-code 1 --python "$repoPath/tools/s3000/export_configurations.py" -- "$deliveryPath/S3000_ADL_8bar_v2026.09.08.4.blend" "$repoPath/src/assets/s3000/assembly.json" $deliveryPath

# Только после успешного завершения Blender.
$env:S3000_GLTF_RUNTIME = "$cachePath/gltf"
node "$repoPath/tools/s3000/optimize_glb.mjs" "$repoPath/src/assets/s3000/s3000-assembly.glb" "$deliveryPath/S3000_ADL_8bar_v2026.09.08.4.glb"
& $inputPython "$repoPath/tools/s3000/verify_assembly.py" "$repoPath/src/assets/s3000"
& $blenderExe --background --factory-startup --python-exit-code 1 --python "$repoPath/tools/s3000/verify_blender_roundtrip.py" -- "$deliveryPath/S3000_ADL_8bar_v2026.09.08.4.glb" "$repoPath/src/assets/s3000/assembly.json" "$cachePath/detail/blender-roundtrip.json"

Set-Location -LiteralPath $repoPath
npm ci
node --test tools/s3000/visibility.test.mjs
npm run build

# После проверки в браузере. В delivery должен находиться ПРОЧИТАЙТЕ.md.
& $inputPython "$repoPath/tools/s3000/package_delivery.py" $repoPath $deliveryPath "$cachePath/delivery-verification.json"
```

После каждой команды проверяйте код завершения. Экспортёр DWG проверяет неизменность SHA-256 оригинала. Конвертер горелки проверяет миллиметры, один блок без поворота/масштабирования и тип polyface. Оптимизатор не принимает уже сжатый GLB, чтобы не перезаписать несжатую поставку. Он проверяет сохранение имён, числа треугольников и общих габаритов после декодирования.

## Выходные файлы и проверка

- `.blend` — 49 корневых компонентов с геометрией, две упакованные текстуры и студийная сцена. Для редактирования отдельного винта используется режим редактирования меша соответствующего компонента. Деаэратор доступен в дереве объектов; в начальном ракурсе рендера он скрыт. По умолчанию видна трасса с экономайзером; `feed_direct` скрыт. Для прямой схемы скрыть `economizer`, `feed_to_economizer`, `feed_from_economizer` и показать `feed_direct` вместе с дочерними мешами.
- Отдельные GLB `WITH_ECONOMIZER` и `DIRECT` содержат по одной готовой схеме питания, включая горелку, без отдельного деаэратора. Библиотечные GLB содержат все варианты; правила видимости применяет конфигуратор.
- Несжатый GLB библиотеки — **124 986 168 байт**, повторно импортирован в чистый Blender.
- Веб-GLB — **16 871 620 байт**, **3 164 288 треугольников**, 98 именованных узла, 18 материалов, две текстуры. Meshopt сжимает данные без сокращения геометрии; декодер включён в страницу.
- `assembly.json` — 49 компонентов, происхождение, положения датчиков и соответствие ведомости. `bom.json` — 27 выбранных строк без цен.
- PNG **2000×1400**: `front-left`, `front-right`, `economizer`, `level-detail`, `burner-detail`, `sensor-detail`, `deaerator-detail`, `deaerator-cladding`, `feed-with-economizer`, `feed-direct`, `cable-detail`, `cabinet-cables`, `deaerator-level`.

Повторный импорт несжатого GLB сохранил все 49 компонентов; максимальная разница границ — `2.384185791015625e-7` м. Meshopt сохранил число треугольников и имена; разница общих габаритов — `0.000027621245695108598` м. Это проверка преобразования данных, а не допуск изготовления.

Фактические результаты сборки, браузера, исходников и MCP записаны в [протоколе версии 4](../../docs/s3000-routing-verification-20260908.json). Инженерная приёмка, испытание на физическом телефоне, размещение на сайте компании, реконструкция котельной и подготовка к 3D-печати в этот результат не входят. Для воспроизведения геометрии горелки нужен оригинал DWG, который не публикуется в репозитории.
