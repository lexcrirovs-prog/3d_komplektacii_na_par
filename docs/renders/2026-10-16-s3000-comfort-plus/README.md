## Воспроизведение

Из корня репозитория, с локальным Vite и настроенным `S3000_BROWSER_RUNTIME`:

```text
node tools/renders/export_s3000_views.mjs http://127.0.0.1:5193/ OUTPUT
node tools/renders/verify_s3000_assets.mjs OUTPUT
blender -b --factory-startup --python-exit-code 1 --python tools/renders/render_s3000_views.py -- --directory OUTPUT --preview
blender -b --factory-startup --python-exit-code 1 --python tools/renders/audit_import.py -- OUTPUT PREMIUM_3xS3000_ComfortPlus_2026-10-16.blend
blender -b --factory-startup --python-exit-code 1 --python tools/renders/render_s3000_views.py -- --directory OUTPUT --reuse
```

После визуального просмотра всех финальных PNG:

```text
python tools/renders/package_s3000_views.py OUTPUT docs/renders/2026-10-16-s3000-comfort-plus --visually-reviewed
```

Второй необязательный аргумент `verify_s3000_assets.mjs` — путь к свежему
манифесту, скачанному с действующего сайта. Он нужен, если подключение Node
к сайту недоступно. Сверка контрольных сумм выполняется в обоих режимах.
